# Bildbriefe fixit247

Ein Schlüsselobjekt pro Gewerk, **mitten im Moment der Panne**. Das Objekt ist heil erkennbar, das Problem steckt als kleine Handlung im Bild (Strahl, Frost, Bruch, Rauchfaden, Schaum). Nah, keine Menschen, keine Hände, kein Text im Bild. Der Ton bleibt ruhig, präzise und modern mit einem Augenzwinkern, nie bedrohlich: kein Feuer, kein Wasserschaden.

## Welt der Bilder: Tiefsee-Studio

Echte Low-Key-Produktfotografie, alle sechs wie aus einem Shooting. Die Farben kommen aus `src/styles/tokens.css`:

- **Raum:** matte Hohlkehle in Tiefsee `#001B2A`. Das Objekt steht auf der Fläche, weicher Kontaktschatten. Kein Raster im Bild (das Raster gehört der Seite).
- **Türkis nur als Lichtkegel:** weicher, gedämpfter Kegel in Türkis `#3AA8B8` hinter dem Objekt, höchstens ein Fünftel der Fläche. Mindestens zwei Drittel des Bildes bleiben dunkel. So bleibt der Anruf-Knopf das hellste Türkis der Seite (SPEC 3).
- **Licht:** große Softbox von links oben, schmales Streiflicht von rechts hinten für eine feine türkise Kante. Schatten nach rechts unten.
- **Akzent:** genau ein Teil pro Bild in Orange `#E8842A`, immer ein echtes Bauteil am Problem, nie Licht oder Reflex.
- **Material:** Chrom mit ruhigen, breiten Lichtkanten, Weiß bleibt weiß, Gummi und Messing matt. Kein HDR, kein Glitzer.
- **Kamera:** für alle gleich, Dreiviertel-Ansicht leicht von oben, 90-mm-Makro. Das Objekt füllt etwa die halbe Bildhöhe.

Die Texte unten gehören nicht auf die Website.
